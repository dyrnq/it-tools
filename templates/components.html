{# 通用组件。 tera 2 把 v1 的「宏」改成了「组件」：宏（`{% macro %}`）和 `{% import %}` 整个 没有了，组件是**全局**的 —— 定义好就能在任何模板里用，不必 import。 三条 Tera 2 的硬性限制决定了这里的写法： 1. 参数要么写字面量（size="40"），要么用 {...} 把表达式包起来 （`{{}}`）—— 跟 JSX 一个路子； 2. 组件的 body **看不见外层的变量** —— v1 的宏能直接读到 base.ui.xxx， 组件不行：body 里只能用它自己声明过的参数。界面上要用的文案 （new_badge / fav_label / drag_hint）得由调用方传进来； 3. 参数名是**封闭**的：多传一个没声明的参数会直接报错。 #} {%- component icon(icon_name: string, size: string = "40", cls: string = "") -%} {%- endcomponent icon -%} {# 工具卡片。收藏态由 app.js 客户端补齐 —— 服务端读不到 localStorage #} {%- component tool_card(card: map, new_badge: string, fav_label: string) -%}
